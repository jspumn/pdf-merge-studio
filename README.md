# PDF Merge Studio 🗂️

A beautiful, **100% free** and **100% private** PDF merger that runs entirely in your browser.

👉 **[Try it live →](https://jspumn.github.io/pdf-merge-studio)**

---

## ✨ Features

- 🔒 **Completely private** — your files never leave your computer
- 📁 **Drag & drop** to upload multiple PDFs at once
- 🔢 **Auto page count** — see how many pages each PDF has
- ↕️ **Reorder** files with up/down buttons or drag-to-sort
- ⚡ **Instant merge** — downloads the result immediately
- 🌐 **Works offline** — no internet required after first load
- 📱 Works on any modern browser (Chrome, Edge, Firefox, Safari)

---

## 🚀 How to Use

1. Open the [live page](https://jspumn.github.io/pdf-merge-studio)
2. Click the upload area or drag your PDF files in
3. Rearrange them in the order you want
4. Type a name for the merged file
5. Click **"Merge PDFs"** and it downloads instantly!

---

## 🛠️ How It Works

Built with pure HTML, CSS, and JavaScript. Uses [pdf-lib](https://pdf-lib.js.org/) for client-side PDF processing — meaning all merging happens in your browser, and no data is ever sent to a server.
